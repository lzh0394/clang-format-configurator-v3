## 1. 字体大小调节（界面字体 + 编辑器字体）

- **状态**：待排期。建议编辑器字号随 M2 的 CM6 接入一起做；界面字号（含持久化）归 M3 的主题/可访问性，均不阻塞 M2 主线。
- **背景**：现在字号是写死的——`src/styles.css` 里 `body { font-size: 14px }`，各组件 11–13px，编辑器区 13px；没有适配大屏 / HiDPI / 视力需求的入口。
- **范围**：
  1. **界面字体**：选项面板、状态栏、按钮、对话框等 UI 文本整体缩放（小 / 标准 / 大 三档，或 85%–120% 的比例）。
  2. **编辑器字体**：源码 / 结果 / 配置 YAML 的等宽字号单独可调，**与界面字号解耦**（改 UI 字号不应改变代码行宽和 diff 的视觉密度）。
  3. **入口**：顶栏设置菜单（或快捷键 `Ctrl/Cmd +` / `-`），提供"恢复默认"。
  4. **持久化**：localStorage，与 M3 的持久化字段一起设计；schema/版本不兼容时回退默认。
- **实现建议**：
  - 统一走 CSS 变量：界面用 `--font-size-ui`（或 `html { font-size }` + rem 化）、编辑器用 `--font-size-editor`；把现有写死字号改成变量派生，避免逐组件硬改。
  - CM6 主题（M2 引入后）直接读 `--font-size-editor`，不要另起一套；当前 textarea/pre 可先接同一变量。
  - **不要用 `transform: scale()`**：会让虚拟列表行高、diff 行号、滚动位置的计算失真。
  - 字号变化后调用虚拟列表的 `virtualizer.measure()` 重新测量动态行高。
  - 可访问性：最小字号不低于 12px；默认仍跟随系统/浏览器设置，只在用户显式调整时覆盖。
- **验收**：
  - 界面与编辑器字号即时变化且互不影响；刷新后保持；恢复默认可撤销。
  - 189 行虚拟列表在三种字号下行高正确、无跳动；导出/导入 roundtrip 与 e2e 回归不受影响。
  - Playwright 补一条：改字号 → 搜索、改选项、导出关键流程仍可用。
